# Repositório de estudo onde implemento um planejador de itinerário de 1(hum) dia(bate-volta) de viagem exemplificando a criação de multiplos agentes simples usando LangGraph.

### Instalação
1. Após o clone, Instale as dependências:

   ```
   pip install -r requirements.txt
   ou
   uv add -r requirements.txt    
   ```


2. Após, execute o script python:

   ```
   uv run python .\TravelPlanner.py
 
   ```
